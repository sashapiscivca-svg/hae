# Code of conduct

[Українська](docs/uk/CODE_OF_CONDUCT.md)

hae is built by and for people who work to save lives. We expect everyone in this project's spaces (issues, pull requests, discussions, chats) to act accordingly.

**Do:** be respectful and patient, assume good faith, give and accept constructive technical criticism, credit others' work, and remember that many contributors and users write in a second language.

**Do not:** harass, insult or demean anyone; make personal or political attacks; use sexualised language or imagery; publish others' private information; or deliberately disrupt discussions.

**Scope.** These rules apply in all project spaces and when someone represents the project in public.

**Enforcement.** Report incidents privately to the maintainers (see [SECURITY.md](SECURITY.md) for the private channel). Maintainers will review every report, keep the reporter's identity confidential, and may warn, temporarily ban or permanently ban participants who break these rules. Decisions are explained to the people involved.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
