# Як долучитися до hae

[English](../../CONTRIBUTING.md)

Дякуємо за допомогу. Найбільше hae покращується завдяки **даним із реального світу**: зйомкам із нових камер і місцевостей, повідомленням про відмови та ретельним вимірюванням. Код теж вітається.

## Як можна допомогти

- **Повідомляйте, де модель не справляється.** Відкрийте issue із назвою моделі, камерою, висотою, кількома кадрами й описом того, що було пропущено чи хибно виявлено. Про чутливі дані можна повідомити приватно (див. [SECURITY.md](SECURITY.md)).
- **Вимірювання на обладнанні:** запустіть `scripts/bench.py` на своїй платі й надішліть результат.
- **Розмічені дані під відкритою ліцензією** (CC0, CC BY або MIT; цивільні; зі згодою, якої вимагає ваша юрисдикція). Ми не можемо прийняти дані, ліцензія яких забороняє комерційне використання чи похідні роботи.
- **Код:** виправлення помилок, прискорення для слабких CPU, краще розбиття на тайли чи трекінг, документація та переклади.

## Основні правила

1. **Жодних сторонніх натренованих ваг.** Кожну модель навчено з нуля, тож її ліцензія залишається чистою. Не додавайте попередньо натреновані backbone, моделі-вчителі чи контрольні точки.
2. **Лише дані з чистими ліцензіями.** Перевірте ліцензію самих даних у їхньому первинному джерелі та зафіксуйте її в `DATA_CARD.md`.
3. **Вимірюйте, а не вгадуйте.** Зміна, яка заявляє про кращу точність, потребує результатів на відкладених підмножинах, отриманих за допомогою `scripts/evaluate.py`. Якщо вона змінює навчання, додайте щонайменше два запуски з різними seed, бо окремий запуск коливається приблизно на ±0,02 AP50.
4. **Середовище виконання має залишатися легким.** `hae.detector` і все, що він імпортує, мають працювати лише з numpy та onnxruntime. PyTorch — для навчання.
5. **Цивільне призначення.** Внески, що слугують видам використання, які [RESPONSIBLE_USE.uk.md](../../RESPONSIBLE_USE.uk.md) визначає як такі, що виходять за межі призначення, не прийматимуться.

## Налаштування середовища розробки

```bash
git clone https://github.com/sashapiscivca-svg/hae && cd hae
pip install -e ".[train,dev,hub]"
pytest -q                 # усі тести працюють на CPU із синтетичними даними; набори даних не потрібні
ruff check src tests scripts
```

## Pull request'и

- Кожен PR має бути сфокусованим; додавайте або оновлюйте тести.
- Код і коментарі пишуться англійською. Документація для користувачів підтримується англійською (`docs/en`) та українською (`docs/uk`). Якщо можете оновити лише одну мову, зазначте це в PR, і ми синхронізуємо іншу.
- Опишіть, що змінилося і як ви це перевірили (команди та результати).
- Роблячи внесок, ви погоджуєтеся, що ваш внесок ліцензується під ліцензією MIT цього проєкту.

## Публікація нових ваг

Для нової чи перенавченої моделі потрібні: YAML-рецепт у `configs/`, ONNX у fp32 та int8 з повними метаданими (з `scripts/export.py`), `safetensors`, `config.json`, `metrics.json` з `scripts/evaluate.py` на всіх відкладених підмножинах її модальності, оновлений `models/SHA256SUMS` і запис у журналі змін.
